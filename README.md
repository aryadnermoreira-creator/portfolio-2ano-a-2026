# Memórias de 2026 — 2º Ano A

Portfólio pedagógico do 2º Ano A do Lar São José, na Cidade de Goiás.

## Conteúdo

- LEIA e AlfaMais;
- Carnaval;
- aniversário do Lar São José e de Dom Jeová;
- FICA, com galeria exclusiva;
- Festa Junina;
- Caminhada da Paz;
- palestras educativas;
- desenhos, cadernos e rotina pedagógica;
- técnica artística de assemblagem e croquis;
- Vivência 5 — cartazes sobre o Brasil;
- projeto Cantando e Cuidando do Rio Vermelho;
- Dia das Crianças;
- Centro Histórico, MUBAN e memória literária;
- eixo curricular sobre povos indígenas;
- propostas de leitura com as famílias.

## Arquivos principais

| Caminho | Função |
|---|---|
| `index.html` | conteúdo e estrutura da página |
| `style.css` | identidade visual e adaptação ao celular |
| `script.js` | menu móvel e ampliação de imagens |
| `assets/images/` | imagens do portfólio |
| `.nojekyll` | publicação estática no GitHub Pages |

## Visualizar localmente

Abra `index.html` no navegador ou execute um servidor estático na pasta:

```powershell
python -m http.server 4173
```

Depois, acesse `http://127.0.0.1:4173`.

## Publicação

O site foi preparado para GitHub Pages a partir da raiz da branch `main`.

Por proteção às crianças, a versão pública não deve incluir contatos, avaliações individuais, informações de saúde ou nomes completos. Novas fotos devem ser publicadas somente depois da conferência das autorizações de uso de imagem.

## Atualizações futuras

Para adicionar uma memória, inclua a imagem em `assets/images/`, crie o bloco correspondente em `index.html` e escreva uma descrição `alt` objetiva. O eixo sobre povos indígenas deve priorizar autoria indígena, diversidade de povos, presença contemporânea, territórios, línguas e direitos, evitando generalizações e estereótipos.
